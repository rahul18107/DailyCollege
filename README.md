
#  DailyCollege

**Turn your college WhatsApp chaos into clean, AI-generated event cards — delivered daily.**

## 🖼️ Overview

![DailyCollege Demo](./assets/demo.gif)

## ✨ Features

- 💬 **WhatsApp parsing** 
- 🤖 **AI event cards** 
- 🎨 **Typed cards** 
- 🔐 **Phone-based auth**
- 👤 **Multi-account**
